# Penpot design scripts

The mobile screens (iPhone, iPad, foldable; light and dark) live in the self-hosted Penpot file **Tipsarr**. They are generated by scripts run through the Penpot MCP plugin (`execute_code`), so a screen can be rebuilt after a change.

- `00_icons.js` … `80_foundations.js`: loaded in `index.txt` order; define helpers (`H`), components (`C`) and screens (`S`) in the plugin `storage`.
- Build a page: `S.go('05 Detail'); S.clearPage(); S.layoutPart(S.detailRest, {cols: 6, yBase: 4500, tag: 'r'})`. Each `execute_code` call must finish in under 120 s (the plugin restarts and `storage` is lost otherwise), so builders stop after `budgetMs` and return `next`.
- Load into the plugin: serve this folder at `http://127.0.0.1:8765/boot/` with `recv.py` (also receives SVG snapshots) and eval each file with `new Function('storage','penpot','penpotUtils', code)`.
- Preview without Penpot's export service: `generateMarkup` → POST to `recv.py` → `render.sh` / `view.sh` (Chromium) after `clean.py` removes Penpot's duplicated flat shape list.
- Icons come from Lucide (ISC), the same set as the web.
- App icon sources: `../icon/`.
