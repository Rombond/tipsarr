# Frontend

SvelteKit SPA (adapter-static) served by the Go binary. Svelte 5 runes, Tailwind 4, shadcn-svelte / bits-ui, openapi-fetch.

- For any `.svelte` / `.svelte.ts` change use the Svelte MCP (`svelte-autofixer`) until clean. Docs: https://svelte.dev/docs/ai/overview/llms.txt
- API types come from `src/lib/api/schema.d.ts`, generated by `make generate` from the backend's OpenAPI spec. Never hand-edit it. Talk only to `/api/v1` (same origin; Vite proxies it in dev, see `.env.example`).
- **Every user-facing string goes through `t('key')`** (`$lib/i18n/index.svelte`); never hard-code English in a template, toast or `confirm()`. Add the key to `../locales/en/web.json` (English is the source; other languages may leave a key out and then show English, `npm run check:i18n` lists gaps and checks placeholders and plural forms; see `../CONTRIBUTING-TRANSLATIONS.md`). Plurals: `"{count} item | {count} items"`. Dates, numbers and money go through `$lib/i18n/format`. Errors: `errorText(e)` maps the server's error `code`. To add a language: new folder in `../locales/` and one line in `../locales/languages.json`, no code change.
- Do not name a variable `state` (it clashes with the `$state` rune).
- In `$effect`, wrap calls that read and write state in `untrack` to avoid loops.
- Request states share one palette: `src/lib/status.ts` (icons, colours) with `ui/status-icon` and `ui/status-badge`.
- Live updates arrive over one shared SSE stream (`events.svelte.ts`).
- Checks: `npm run check`, `npm run check:i18n`, `npm run build`.
