# Android app

Kotlin + Jetpack Compose, module `app`, package/applicationId `com.brebond.tipsarr`.

- Build: `./gradlew assembleDebug`, release `./gradlew bundleRelease` (minified, resource shrinker on).
- Version in `app/build.gradle.kts`: `appVersion` (versionName) and `versionCode` (bump for every Play upload).
- Release signing: `keystore.properties` and the keystore live outside git; without them the release build is unsigned. `app/google-services.json` (FCM) is git-ignored: push needs it locally.
- Generated by `make generate`, never edit: `res/values*/strings.xml`, `core/support/GeneratedLanguages.kt`, `design/Tokens.kt`, `src/main/openapi/openapi.yaml`. Change strings in `locales/`.
- Strings are looked up by generated name (`stringByName`, `perm_*`, `error_*`), invisible to the shrinker: `res/raw/keep.xml` keeps them all; keep it.
