# Tipsarr iOS

SwiftUI app (iOS 26+, iPhone and iPad, adaptive for the foldable). Not started: the Xcode project is created on the Mac following the handoff note in the vault (`Serveur/Dev/Tipsarr/mobiles/Tipsarr iOS.md`).

Inputs already in the repo:
- `../api/openapi.yaml`: the API (OpenAPI 3.0.3), generate the client with swift-openapi-generator.
- `../design/generated/Tokens.swift`: colours, spacing, radii, type sizes.
- `../design/generated/Localizable.xcstrings`: en/fr strings (web catalogs + mobile-only).
- `../design/icon/`: app icon (light, dark, tinted).
- Screens: self-hosted Penpot file "Tipsarr" (pages 00-11); scripts in `../design/penpot/`.
